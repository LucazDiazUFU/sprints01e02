# S1_02 — Requisitos funcionais

Os requisitos abaixo são uma proposta inicial baseada nos cartões da Sprint 1. O enunciado completo do Trabalho 1 deve ser conferido antes da entrega final.

| ID | Tipo | Requisito |
| --- | --- | --- |
| RF01 | Cadastro | Cadastrar um ativo com ID único, nome, tipo, responsável e localização. |
| RF02 | Consulta | Listar os ativos cadastrados e consultar um ativo pelo ID. |
| RF03 | Atualização | Alterar os dados de um ativo existente sem trocar seu ID. |
| RF04 | Remoção | Remover um ativo pelo ID, respeitando o vínculo com vulnerabilidades. |
| RF05 | Cadastro | Cadastrar uma vulnerabilidade com ID, descrição, grau de 0 a 10 e ID de um ativo existente. |
| RF06 | Consulta | Listar as vulnerabilidades e consultar aquelas vinculadas a um ativo. |
| RF07 | Atualização | Alterar descrição, grau ou situação de uma vulnerabilidade cadastrada. |
| RF08 | Remoção | Remover uma vulnerabilidade pelo ID. |
| RF09 | Validação | Recusar campos obrigatórios vazios, IDs repetidos e graus fora de 0 a 10. |
| RF10 | Persistência | Salvar e carregar os registros em arquivo para uso em outra execução. |

## Casos de uso

**Cadastrar ativo:** o responsável informa ID, nome, tipo, responsável e localização. O programa verifica os campos e a duplicidade do ID. Se os dados forem válidos, registra o ativo e confirma o cadastro.

**Consultar ativo:** o responsável informa um ID. O programa procura o registro e apresenta seus dados. Se não existir, informa que o ativo não foi encontrado.

**Cadastrar vulnerabilidade:** o responsável informa o ID da vulnerabilidade, a descrição, o grau e o ID do ativo. O programa verifica a faixa do grau, a duplicidade e a existência do ativo. Depois registra a vulnerabilidade ou explica por que não foi possível cadastrá-la.

Uma regra ainda precisa ser decidida no enunciado final: ao excluir um ativo com vulnerabilidades, o sistema deve impedir a exclusão ou tratar os registros vinculados de outra forma. Nos exercícios, a opção adotada é impedir a exclusão até resolver o vínculo.
