# S1_16 — Git fundamentos

O Git registra alterações no projeto. `git status` mostra o que mudou, `git add` prepara os arquivos, `git commit` grava uma versão e `git log` apresenta o histórico. O repositório local funciona mesmo sem GitHub. O remoto permite publicar e receber mudanças com `push` e `pull`.

## Roteiro para o projeto

```bash
git init
git status
git add s1_10.py
git commit -m "Adiciona cadastro de ativos em lista"
git add s1_12.py
git commit -m "Adiciona cadastro de vulnerabilidades"
git add s1_14.py
git commit -m "Salva vulnerabilidades em JSON"
git log --oneline
```

Para publicar, crio um repositório vazio na minha conta do GitHub e uso a URL exibida por ele:

```bash
git remote add origin URL_DO_REPOSITORIO
git branch -M main
git push -u origin main
```

Para trabalhar a partir de um repositório já publicado: `git clone URL_DO_REPOSITORIO`, `git log --oneline` e `git pull`. O histórico de três commits locais pode ser feito com os arquivos desta Sprint. A publicação precisa ser executada em uma conta GitHub real; este arquivo não é prova de um `push`.
