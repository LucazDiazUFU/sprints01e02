# S3_05 — Busca e ordenação

Bubble Sort troca vizinhos fora de ordem. A versão implementada para quando não há trocas: melhor caso O(n), pior O(n²), e é estável. Selection Sort procura o menor em cada posição: sempre faz n(n-1)/2 comparações; a troca pode alterar a ordem de itens com chaves iguais. Insertion Sort insere cada item no trecho já ordenado: melhor O(n), pior O(n²), estável e útil em listas pequenas ou quase ordenadas.

As funções retornam uma cópia ordenada e o total de comparações; a entrada original continua disponível. Aceitam key para ordenar ativos por nome ou ID. As três usam O(n) para essa cópia, embora o algoritmo sobre a cópia opere com O(1) espaço adicional.

A busca binária compara o elemento central com o valor procurado e elimina metade do intervalo. Retorna índice None quando não encontra. A entrada deve estar ordenada pelo mesmo critério. Busca binária não é adequada para uma lista encadeada sem acesso rápido ao meio.

s3_05.py compara entradas invertidas de 10, 50 e 100 elementos e aplica ordenação a ativos. A tabela real está em evidencias/s3_05.txt. Os testes incluem lista vazia, repetidos, ordenada, invertida e limites da busca.
