# S3_13 — Lógica proposicional e argumentação

P representa “o ativo está cadastrado” e Q “a entrada é válida”. AND exige ambos; OR exige pelo menos um; NOT inverte. A implicação P→Q só é falsa quando P é verdadeiro e Q falso. A equivalência é verdadeira quando os valores são iguais.

De Morgan: ¬(P∧Q) equivale a ¬P∨¬Q; ¬(P∨Q) equivale a ¬P∧¬Q. O script percorre as quatro combinações e confere as equivalências. P∨¬P é tautologia; P∧¬P é contradição.

Modus ponens: P→Q, P, portanto Q. Modus tollens: P→Q, ¬Q, portanto ¬P. Afirmar o consequente é inválido: P→Q, Q não garante P. Se “ser servidor implica ser equipamento”, um notebook também é equipamento e não é servidor.

No cadastro, a autorização de uma alteração pode ser escrita C∧V, onde C indica credencial válida e V entrada válida. ¬C∨¬V representa o bloqueio equivalente por De Morgan. Lógica define a regra, mas a implementação também precisa validar os dados e tratar erros. Execute s3_13.py para tabelas, equivalências, tautologia e contraexemplo.
