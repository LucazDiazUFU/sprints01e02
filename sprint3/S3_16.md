# S3_16 — Front-end moderno

A interface usa HTML semântico, CSS Grid, variáveis de cor e regras responsivas. O conteúdo principal muda de colunas para uma coluna em telas menores. Tabelas podem rolar horizontalmente. Os controles têm área de toque e foco visível.

app.js guarda ativos como um array de objetos. map apresenta dados, filter atende a busca e os filtros, find localiza o item em edição e reduce calcula totais. Formulários enviam o JSON à API. A lista é recarregada após salvar ou excluir para refletir o estado persistido.

A edição usa os mesmos campos do projeto anterior. Vulnerabilidades ficam ligadas a um ativo. As dependências têm ativo receptor, ativo de origem e peso. A vista de risco mostra b e x por ID. O fator de exposição é opcional.

Os dados recebidos são escritos com textContent, sem inserir nomes como HTML. O token opcional fica apenas em memória. Os arquivos são web/index.html, estilo.css e app.js. Execute a API e abra http://127.0.0.1:5000. A sintaxe JavaScript foi verificada; navegação e aparência devem ser conferidas em navegador.
