# S3_02 — Funções de alta ordem e recursão

Fatorial calcula n! multiplicando de 1 até n. A versão iterativa usa um laço; a recursiva reduz o problema até 0! = 1. As duas fazem O(n) multiplicações, mas a recursiva usa O(n) espaço de pilha, enquanto a iterativa usa O(1) espaço auxiliar. Valores negativos são recusados.

Fibonacci usa F(0)=0, F(1)=1 e F(n)=F(n-1)+F(n-2). A versão ingênua recalcula os mesmos termos e cresce exponencialmente. A versão com lru_cache guarda resultados, reduzindo o número de subproblemas a O(n), com memória O(n). Os limites do exercício evitam excesso de tempo e de profundidade da pilha.

map transforma os ativos em nomes, filter seleciona uma categoria, lambda define uma ordenação e reduce acumula dados. São funções de alta ordem porque recebem funções como argumentos. A ordenação do Python custa O(n log n) no pior caso; a chave lambda não muda essa ordem.

O script mede com perf_counter as versões de Fibonacci. Os tempos em evidencias/s3_02.txt são desta execução, não uma garantia para outros computadores. Execute `python3 -m sprint3.s3_02`. Os testes conferem valores pequenos conhecidos, equivalência entre versões e entradas inválidas.
