# S3_17 — JavaScript assíncrono e APIs

assincrono.js mostra uma função baseada em callback e sua adaptação para Promise. Promise representa um resultado futuro; resolve entrega o resultado e reject sinaliza falha. async permite usar await para esperar a Promise sem bloquear toda a interface.

O exercício consulta /api/ativos e a API pública do IBGE para o município de Uberlândia. fetch não rejeita automaticamente respostas HTTP 400 ou 500: por isso resposta.ok é conferido antes de response.json. AbortController limita a espera a dez segundos. try/catch apresenta erros de rede, tempo e resposta inválida ao usuário.

A API pública pode ficar indisponível e depende de acesso à internet. O inventário local continua disponível sem essa consulta. A política CSP permite a conexão ao domínio do IBGE e ao próprio servidor.

Abra http://127.0.0.1:5000/web/assincrono.html. app.js usa a mesma abordagem para as operações do inventário. A validação sintática não substitui um teste real da API externa. A documentação oficial da fonte está em https://servicodados.ibge.gov.br/api/docs/localidades.
